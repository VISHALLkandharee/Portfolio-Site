Multi-tenant SaaS

Task-Flow

Team task management SaaS with tenant-isolated workspaces, subscription billing and live collaboration.

Live app Source
  • Complete multi-tenant SaaS with Stripe subscription billing and webhook handling: workspaces are data-scoped at the database level, and RBAC is enforced at both API and UI across three permission tiers (Admin, Manager, Member).
  • Drag-and-drop Kanban board powered by Socket.io, so task updates broadcast instantly to everyone in the workspace with no page refresh.
  • BullMQ and Redis job queue handling email notifications, assignment alerts and scheduled reminders asynchronously, fully decoupled from the API request cycle.
